Alur Pembayaran & License Key

  1. Buat request pembayaran.
  2. WhatsApp Developer terbuka dengan Order ID, Network ID, Store ID, dan email Owner.
  3. Ikuti instruksi pembayaran Developer dan kirim bukti transfer.
  4. Developer menandai pembayaran paid.
  5. Developer membuat License Key manual yang terikat ke Network dan akun Owner.
  6. Developer menyerahkan Store ID + email akun customer + License Key melalui WhatsApp.
  7. Customer login sebagai Owner, buka license.html, lalu aktifkan License Key.
Lisensi baru aktif setelah License Key dimasukkan oleh Owner. Key tidak diaktifkan hanya karena pembayaran sudah dikonfirmasi.
